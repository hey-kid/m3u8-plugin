M3U8 Catcher (M3U8 捕手)

Privacy Policy

Last updated: October 29, 2026 · Covers the data practices of version 0.3.2

This policy explains how the M3U8 Catcher extension for Microsoft Edge handles playlist URLs and related information, and how you can view, manage, and delete that information.

At a glance: The extension identifies, displays, and stores HLS playlist URLs requested by webpages locally on your device. It does not automatically upload captured records to the developer or third-party servers, and it does not use advertising, analytics, or tracking services.

1. Information the extension handles

To discover and manage playlist URLs, the extension observes relevant webpage network request metadata and handles the following information:

  • Complete m3u8/HLS resource URLs, resource domains, detection methods, and HTTP request methods.
  • The URL and title of the most recently associated source webpage.
  • HTTP response status, network errors, first and most recent capture times, and cumulative capture counts.
  • Tab, document, and navigation state used to distinguish the current webpage and associate requests with their source.

Complete URLs may contain query parameters, temporary signatures, access tokens, or other authorization parameters generated by the source website. The extension preserves these parameters so that you can copy the complete URL. It does not actively read account passwords, cookies, or login forms, and it does not read or store webpage body content, images, or video files.

2. How information is used

This information is used only to identify playlists, display resources from the current webpage, classify request status, copy complete URLs, and provide local history search, deletion, and JSON backup export. The extension does not use it for advertising profiles, data sales, creditworthiness assessment, or lending purposes.

The current version does not download, play, or merge videos. The normal status category means that an HTTP 2xx response was observed without a network error; it does not guarantee that a resource is playable.

3. Local storage

Long-term history is stored in the extension's local IndexedDB database on your current device and within your current Edge profile. Current-page results and request association state use extension session storage. History change notifications and storage error status use extension local storage.

The extension does not use cloud synchronization. It does not automatically delete history from regular browsing windows when you refresh a webpage, close a tab, or restart the browser normally. Available storage, browser configuration, and device changes may affect local data. You can export backups as needed.

4. Data transfers and actions you initiate

The extension does not automatically send captured records to the developer or third parties. It does not include advertising, analytics, or user tracking services.

When you click a copy button, the selected URLs are written to the system clipboard. When you export a backup, records are written to the local JSON file you save. Subsequent clipboard synchronization, access by other applications, and files you choose to share depend on your operating system, applications, and actions. Please manage clipboard contents and backup files containing complete URLs with care.

If you choose to contact the developer, the contact information and issue details you send will be used to respond to your support request. Please do not post complete URLs that grant access to resources in public feedback.

5. Retention and deletion

The extension does not automatically expire history records based on age. You can view and manually delete records in the global history view, and export a complete backup.

Deleting a history record does not also clear the current webpage's temporary list. If the same URL is captured again later, the extension may save it again. You are responsible for managing and deleting previously exported backup files and copied content.

To stop future capture, you can change the extension's site access permissions, disable it, or uninstall it through Edge extension management. Changing permissions or disabling the extension does not automatically delete existing history.

6. InPrivate windows

If you allow the extension to run in InPrivate windows, captures from those windows are used only for temporary lists and are not written to the long-term history database used by regular browsing windows.

7. Visiting this policy webpage

This policy webpage does not include analytics scripts, advertising, or tracking code. When you visit it, the hosting provider may record necessary access logs under its own policies. This is separate from the records stored by the extension, which does not upload captured records to the webpage's hosting provider.

8. Policy updates and contact

When the extension's features or data practices change, we will update this policy and its last updated date, and update the corresponding store data usage disclosures as required.
